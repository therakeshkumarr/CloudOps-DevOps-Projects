# AWS Account Setup Guide: Create an AWS Free Account, Configure Billing & Free Tier Alerts

A practical beginner-friendly guide for creating and activating an **Amazon Web Services (AWS) account**, understanding the **AWS Free Tier / Free account plan**, completing billing and identity verification, selecting the appropriate support plan, and configuring **Free Tier usage alerts**.

This guide is written as a standalone project document for learning and portfolio use. It focuses only on the **AWS account setup and billing workflow**. Account security topics such as root-user MFA are intentionally outside the scope of this document.

---

## 📌 Project Overview

Before working with services such as Amazon EC2, Amazon S3, Amazon VPC, Amazon RDS, or AWS Lambda, you need an active AWS account.

The account creation process includes several stages:

1. Create the AWS account.
2. Verify the root-user email address.
3. Create a strong root-user password.
4. Choose the appropriate AWS account plan.
5. Enter contact and billing information.
6. Complete identity verification.
7. Select a support plan.
8. Wait for account activation.
9. Configure AWS Free Tier usage alerts.
10. Verify that the account is ready for cloud projects.

> **Important:** An AWS Free account is not the same thing as unlimited free AWS usage. AWS provides free offers, credits, and service-specific limits. Always check the current Free Tier terms and monitor your usage.

# 1. What Is an AWS Account?

An **AWS account** is the environment where you create and manage AWS cloud resources.

Think of it as your own cloud workspace. Inside the account, you can create infrastructure, configure services, manage users and permissions, and monitor usage and billing.

An AWS account has a **root user**. The root user is the original account owner created during registration and has very high-level access to the account.

### Root User

The root user is created when you sign up for AWS.

The root-user email address is important because it is used for account access and account recovery.

For a personal learning account, use an email address that you control and regularly monitor.

For a company account, AWS recommends using stable organizational contact information so access does not depend on one employee.

# 2. AWS Free Tier and Free Account Plan

AWS provides several types of free usage offers. The exact offers and limits can change, so always check the current AWS documentation before starting a project.

At the time of writing, new AWS customers receive **USD $100 in credits** after creating an account and can earn up to **another USD $100** by completing eligible activities. AWS also provides access to more than 30 services with monthly Always Free usage limits. citeturn0search0turn0search1

The current **Free account plan** is intended for learning, experimentation, and building applications within the plan's supported limits. The Free account plan ends after **six months or when the available credits are fully used, whichever occurs first**. citeturn0search0

After the Free account plan ends, AWS states that the account closes automatically unless it is upgraded to a paid account plan. AWS retains the content for a limited period after closure. citeturn0search0

### AWS Free Tier is not "everything is free"

Some AWS services, features, or usage levels can create costs depending on the account plan and the resource being used.

Before launching a resource, check:

- Whether the service has a Free Tier offer.
- What the monthly free limit is.
- Whether the offer is Always Free or time-limited.
- Whether your account is on the Free or Paid plan.
- Whether your usage can exceed the free allowance.

Official AWS Free Tier documentation:

[https://aws.amazon.com/free/](https://aws.amazon.com/free/)

# 3. Before You Start

Prepare the following before creating the account:

- A working email address that you can access immediately.
- A mobile phone that can receive verification messages.
- Your personal or business contact information.
- A valid payment method accepted by AWS.
- A strong, unique password.
- Access to your email inbox during the entire registration process.

### Recommended Password Practice

Do not reuse an old password from another website.

Use a long, unique password and consider using a password manager such as 1Password, Bitwarden, or a trusted browser password manager.

AWS may also reject passwords that have appeared in publicly known data leaks. citeturn0search4

# 5. Create the Root User Password

After verifying your email, AWS asks you to create a password for the root user.

Enter a strong, unique password.

![Password creation screen](https://nextwork.ai/projects/static/aws-account-setup-v2/password-creation-screen1771454792685.webp)

Then:

1. Enter the password.
2. Enter it again to confirm.
3. Click **Continue**.

### Why the Root Password Matters

The root user has extensive access to the AWS account.

Treat the root-user password as a high-value credential.

Do not:

- Share it with other people.
- Put it inside GitHub repositories.
- Put it inside source code.
- Reuse it on other websites.
- Store it in plain text.

For normal cloud administration, AWS recommends using appropriate identity and access-management mechanisms instead of using the root user for everyday work.

# 6. Choose the AWS Account Plan

After the initial account information is completed, AWS asks you to choose an account plan.

For a beginner who wants to learn AWS without immediately moving to unrestricted pay-as-you-go usage, select:

**Choose free plan**

![Choose your account plan page with Free and Paid options](https://nextwork.ai/projects/static/aws-account-setup-v2/choose-your-account-plan-page-with-free-and-paid-options1771455554653.webp)

## Free Account Plan

The Free account plan is designed for exploring AWS within the services and limits supported by the plan.

According to current AWS documentation:

- New customers receive **$100 in sign-up credits**.
- Eligible activities can provide up to **another $100 in credits**.
- The Free account plan lasts up to **six months or until credits are fully used**, whichever comes first.
- The Free account plan does not allow access to every AWS service or feature.
- After the Free account plan ends, the account closes unless you upgrade to a Paid account plan. citeturn0search0turn0search1

AWS Free Tier documentation:

[https://aws.amazon.com/free/](https://aws.amazon.com/free/)

### Free Plan vs Paid Plan

The basic difference is:

| Free account plan | Paid account plan |
|---|---|
| Designed for learning and experimentation | Designed for broader AWS usage |
| $100 sign-up credits for new customers | $100 sign-up credits for new customers |
| Up to another $100 can be earned through eligible activities | Up to another $100 can be earned through eligible activities |
| Access to supported Free Tier services/features | Broader access to AWS services/features |
| Ends after six months or when credits are fully used | Continues with standard pay-as-you-go billing |
| Account closes when the Free plan ends unless upgraded | Account remains active |

AWS's current account-plan documentation should be treated as the final authority because plan features and eligibility can change. citeturn0search0

# 8. Add a Payment Method

AWS requires a valid payment method during account registration.

On the **Billing Information** page, enter your accepted credit or debit card details.

![Billing information form with credit card fields](https://nextwork.ai/projects/static/aws-account-setup-v2/billing-information-form-with-credit-card-fields1771460518931.webp)

AWS uses payment information as part of account verification and billing.

### Does Adding a Card Mean You Will Immediately Be Charged?

No.

Being asked for a payment method does not mean that your Free account plan immediately starts charging you.

AWS may perform a temporary authorization to verify the payment method. AWS currently documents a temporary USD $1 authorization for some sign-up flows; the exact verification process can vary by account and region. citeturn0search2

For AWS India accounts, AWS documents a **₹2 card verification charge that is refunded after verification**. citeturn0search7

![Payment method entry form](https://nextwork.ai/projects/static/aws-account-setup-v2/payment-method-entry-form1771460518931.webp)

### If Your Card Is Declined

If the payment method is rejected:

1. Check that the card information is correct.
2. Check that the card supports the required transactions.
3. Contact your bank if necessary.
4. Try another valid payment method if AWS permits it.

Some prepaid or virtual cards may not be accepted.

# 10. If AWS Says You Are Not Eligible for the Free Plan

You may see a message such as:

> **You are not eligible for the free plan**

This can happen when AWS determines that the registration information is associated with an existing or previously registered AWS account or otherwise does not meet Free account-plan eligibility requirements.

![You are not eligible for the free plan message](https://nextwork.ai/projects/static/aws-account-setup-v2/you-are-not-eligible-for-the-free-plan-message1771461565090.webp)

Do not create multiple accounts simply to try to bypass eligibility restrictions.

Read the message shown by AWS and follow the account-registration instructions provided.

If AWS requires you to continue with a Paid account plan, remember that Paid accounts use standard AWS pricing for eligible usage beyond available credits or free allowances. citeturn0search0

If you need help with an account-specific registration problem, use AWS Support or the official AWS account-management documentation.

# 15. Why Free Tier Alerts Matter

A common beginner mistake is assuming:

> "I am using AWS Free Tier, so I never need to check billing."

That is not a safe assumption.

Free Tier offers have specific limits and conditions. Your account plan also affects which offers and services are available.

AWS recommends monitoring Free Tier usage, and its billing tools can show your usage and credit information. citeturn0search10

Before creating resources, check the expected cost and Free Tier eligibility.

After creating resources, monitor:

- Running EC2 instances
- EBS volumes
- Elastic IP-related resources
- NAT Gateway usage
- Data transfer
- RDS instances
- Load balancers
- S3 storage and requests
- CloudWatch usage
- Other resources created during labs

Some services can generate costs quickly if used outside the applicable free allowance.

# 17. Important Difference: Free Tier vs Free Account Plan

These terms are easy to confuse.

### AWS Free Tier

The **AWS Free Tier** is the collection of AWS free usage offers.

Depending on the service and account plan, these can include:

- Always Free offers.
- Time-limited trials.
- Free usage covered by credits.

The exact service limits are different for each AWS service. citeturn0search1

### AWS Free Account Plan

The **Free account plan** is an account-plan option available during AWS registration.

It is designed to let new customers explore supported AWS services without incurring charges while the Free account plan is active and within its applicable conditions. The current plan ends after six months or when the credits are fully used, whichever occurs first. citeturn0search0

### Simple Way to Remember

```text
AWS Free Tier
    |
    +-- Free usage offers
    +-- Service-specific limits
    +-- Always Free offers
    +-- Credits / trials depending on plan

AWS Free Account Plan
    |
    +-- Account-level plan
    +-- $100 sign-up credits
    +-- Up to $100 additional eligible credits
    +-- Up to 6 months
    +-- Restricted service/feature access
```

# 18. What Happens After the Free Account Plan Ends?

The Free account plan ends when:

- The six-month plan period ends, or
- The available credits are fully used,

whichever happens first. citeturn0search0

AWS states that the Free account plan then closes automatically unless you upgrade to a Paid account plan.

If you want to continue using the account, review the available upgrade options before the plan ends.

For a Paid account plan, standard AWS pay-as-you-go pricing applies to eligible usage beyond applicable credits or free allowances. citeturn0search0
