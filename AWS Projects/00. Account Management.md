Your AWS account is live, but is it _secured_ the way a cloud professional would do it?

Cloud professionals enable

multi-factor authentication (MFA)

on their accounts. It's a non-negotiable security practice. AWS itself flags accounts without MFA as a critical security risk. In this secret mission, you will do exactly what real cloud engineers do on day one.

**In this secret mission, get ready to:**

Explore the IAM Dashboard

Set up a virtual authenticator app.

Enable MFA on your root account.

> 💡 Why does the root account need MFA?
> 
> The
> 
> root user
> 
> controls everything in your AWS account. If your password is stolen, an attacker can do anything.
> 
> Multi-factor authentication (MFA)
> 
> adds a second, app-based proof, so your account stays secure even if your password is compromised.

**Navigate to the IAM Dashboard**

-   In the AWS Management Console, type IAM in the search bar at the top.
    
-   Click **IAM** in the search results.
    

![Searching for IAM in the console search bar](https://nextwork.ai/projects/static/aws-account-setup-v2/searching-for-iam-in-the-console-search-bar1771473189463.webp)

Searching for IAM in the console search bar

> 💡 What is IAM?
> 
> IAM
> 
> stands for Identity and Access Management. It is the AWS service that controls who can access your account and what they can do. The IAM Dashboard gives you an overview of your account's security posture, including whether MFA is enabled.

-   On the IAM Dashboard, look for the **Security recommendations** section.
    

You should see **Add MFA for root user** for the root account.

![IAM Dashboard showing MFA not enabled warning](https://nextwork.ai/projects/static/aws-account-setup-v2/iam-dashboard-showing-mfa-not-enabled-warning1771473484318.webp)

IAM Dashboard showing MFA not enabled warning

**Download an authenticator app**

If you do not already have an authenticator app on your phone, download one of these free options:

-   **Google Authenticator** ([iOS](https://apps.apple.com/app/google-authenticator/id388497605) / [Android](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2))
    
-   **Microsoft Authenticator** ([iOS](https://apps.apple.com/app/microsoft-authenticator/id983156458) / [Android](https://play.google.com/store/apps/details?id=com.azure.authenticator))
    

Both apps are completely free. If you already use a password manager like 1Password or Bitwarden, it can also generate these codes and you do not need a separate app.

> 💡 What is an authenticator app?
> 
> An
> 
> authenticator app
> 
> generates a new 6-digit code every 30 seconds. When you log in to AWS, you enter your password _and_ the current code from the app. Since the code changes constantly and only exists on your phone, it is nearly impossible for an attacker to guess or steal it.

-   Follow the setup instructions for the app you downloaded.
    

**Enable MFA on the root account**

-   In the **Security recommendations** section, click **Add MFA**.
    

![Add MFA button in the security recommendations](https://nextwork.ai/projects/static/aws-account-setup-v2/add-mfa-button-in-the-security-recommendations1771473567917.webp)

Add MFA button in the security recommendations

-   For **MFA device name**, enter a name like my-phone or root-mfa.
    

![MFA device name field with root-mfa entered](https://nextwork.ai/projects/static/aws-account-setup-v2/image1771473651844.webp)

MFA device name field with root-mfa entered

-   Select **Authenticator app** as the MFA device type.
    

![MFA device options with Authenticator app selected](https://nextwork.ai/projects/static/aws-account-setup-v2/image1771473656145.webp)

MFA device options with Authenticator app selected

-   Click **Next**.
    
-   Click the **Show QR code** button.
    

![Show QR code button on the authenticator app setup page](https://nextwork.ai/projects/static/aws-account-setup-v2/image1771474188303.webp)

Show QR code button on the authenticator app setup page

You should see a **QR code** on screen.

![QR code displayed for scanning with your authenticator app](https://nextwork.ai/projects/static/aws-account-setup-v2/image1771474192788.webp)

QR code displayed for scanning with your authenticator app

-   Open your authenticator app on your phone.
    
-   Tap the **+** button (or **Add account**) in the app.
    
-   Select **Scan QR code** and point your phone camera at the QR code on screen.
    

Your authenticator app on your phone will now show a 6-digit code that refreshes every 30 seconds.

-   Enter the **first code** in the **MFA code 1** field.
    

![MFA Code 1 entry field for the first authenticator code](https://nextwork.ai/projects/static/aws-account-setup-v2/image1771473898029.webp)

MFA Code 1 entry field for the first authenticator code

-   Wait for the code to refresh (a new code will appear every 30 seconds).
    
-   Enter the **second code** in the **MFA code 2** field.
    

![MFA Code 2 entry field for the second consecutive code](https://nextwork.ai/projects/static/aws-account-setup-v2/image1771473894895.webp)

MFA Code 2 entry field for the second consecutive code

-   Click **Add MFA**.
    

Your root account is now secured with multi-factor authentication.

![Two consecutive MFA codes entered in the form](https://nextwork.ai/projects/static/aws-account-setup-v2/two-consecutive-mfa-codes-entered-in-the-form1771474016296.webp)

Two consecutive MFA codes entered in the form

Here are some tips to help resolve your issue:

1.  Make sure you are entering two **_different_** consecutive codes, not the same code twice.
    
2.  Wait for the code to change in your authenticator app before entering the second one. The codes are time-sensitive, so enter them promptly.
